# Forbes Billionaires Dashboard (Power BI)

## 📊 Overview
This project presents an interactive Power BI dashboard that analyzes global billionaire wealth distribution using the Forbes Billionaires dataset.

The dashboard helps explore insights such as:
- Wealth distribution by country
- Top richest billionaires
- Industries with the most billionaires
- Net worth trends and comparisons

## 📂 Dataset
The dataset is based on the Forbes Billionaires list and contains information about:
- Billionaire Name
- Net Worth
- Country
- Industry
- Age
- Company
- Source of wealth

## 📑 Dashboard Pages

### 1️⃣ Global Overview
Provides a high-level view of:
- Total Billionaires
- Total Net Worth
- Average Net Worth
- Distribution by country

### 2️⃣ Top Billionaires
Shows:
- Top richest billionaires
- Ranking using DAX
- Net worth comparison

### 3️⃣ Industry Analysis
Displays:
- Billionaires by industry
- Industry wealth distribution
- Comparative insights between sectors

## ⚙️ Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
